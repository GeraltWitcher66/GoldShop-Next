# گالری زرین — دموی استاتیک Next.js

سایت دموی فروشگاه طلا و جواهر با **Next.js 14 (App Router)**، **Tailwind CSS** و **RTL** کامل.
تمام داده‌ها در فرانت‌اند و به‌صورت Hardcoded تعریف شده‌اند و خروجی با `output: 'export'`
برای **GitHub Pages** آماده می‌شود.

---

## ۱) اجرا

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # خروجی استاتیک در پوشه out/
```

> خروجی استاتیک (`out/`) شامل HTML، JS و CSS است و هیچ سروری لازم ندارد.

---

## ۲) ساختار پروژه

```
app/
  layout.jsx          # html با dir="rtl" + متادیتا
  page.jsx            # صفحه اصلی (ترکیب بخش‌ها)
  globals.css         # استایل‌های پایه: شیشه‌ای، طلایی، دکمه‌ها
  icon.svg            # فاویکون
  products/[slug]/page.jsx  # صفحه جزئیات محصول (generateStaticParams)
context/
  CartContext.jsx     # سبد خرید: Context + localStorage + ثبت سفارش
components/
  Header.jsx          # نوار نرخ طلا + هدر شیشه‌ای + آیکون سبد
  GoldPriceBar.jsx    # نوار باریک نرخ لحظه‌ای طلا
  Hero.jsx            # بخش تمام‌صفحه با تایپوگرافی بزرگ و دکمه طلایی
  CategoryGrid.jsx    # چهار دسته‌بندی دایره‌ای با هاور زوم
  ProductCard.jsx     # کارت محصول، لینک به صفحه اختصاصی محصول
  ProductGrid.jsx     # گرید ۴ ستونه
  FeaturedProducts.jsx # تب‌های پرفروش‌ترین‌ها و جدیدترین‌ها
  TrustSection.jsx    # تضمین اصالت، ارسال بیمه‌شده و فاکتور رسمی
  ProductImage.jsx    # تصویر محصول با پلیس‌هولدر (Client Component)
  AddToCartButton.jsx # دکمه «افزودن به سبد» در صفحه محصول
  CartSidebar.jsx     # کشوی سبد خرید + جمع کل + ثبت سفارش
  CartToast.jsx       # پیام موفقیت ثبت سفارش
  ProductReviews.jsx  # نظرات هر محصول + اسلایدر افقی
  AboutSection.jsx    # درباره ما + آمار
  Footer.jsx          # شبکه‌های اجتماعی، تماس تهران، کپی‌رایت
data/
  products.js         # آرایه محصولات (re-export فرمت‌کننده‌ها)
  goldPrices.js       # نرخ مثقال طلا و گرم ۱۸ عیار
lib/
  format.js           # ارقام فارسی + فرمت قیمت
  path.js             # پیشوند basePath برای مسیر عکس‌ها در GitHub Pages
public/images/        # محل قرار دادن عکس‌های واقعی
```

### محصولات

برای تغییر محصولات فقط `data/products.js` را ویرایش کنید:

```js
{
  id: 'ruby-ring',
  slug: 'ruby-solitaire-ring', // آدرس صفحه: /products/ruby-solitaire-ring
  name: 'انگشتر تک‌نگین یاقوت',
  category: 'انگشتر',
  karat: 21,
  weight: '۵٫۱ گرم',
  stone: 'یاقوت سرخ طبیعی',
  price: 28900000,
  image: '/images/ring-1.jpg',
  description: '...',
}
```

قیمت‌ها به تومان و به‌صورت عدد خام ذخیره می‌شوند؛ `formatPrice()` آن‌ها را به
`۲۸,۹۰۰,۰۰۰` تبدیل می‌کند.

## ۳) عکس‌هایی که باید در `public/images` بگذارید

همه عکس‌ها **محلی** هستند؛ هیچ لینک اینترنتی در پروژه استفاده نشده است.
تا زمانی که فایل‌ها را اضافه نکنید، به‌جای عکس یک پلیس‌هولدر گرادیانی طلایی
نمایش داده می‌شود و ظاهر سایت به‌هم نمی‌ریزد.

| نام فایل | کاربرد | ابعاد پیشنهادی | نسبت | حجم هدف |
| --- | --- | --- | --- | --- |
| `hero-bg.jpg` | پس‌زمینه بخش Hero | **۲۴۰۰ × ۱۶۰۰** | ۳:۲ | زیر ۴۰۰KB |
| `hero-side.jpg` | عکس قاب سمت چپ هیرو (از تبلت به بالا) | **۱۲۰۰ × ۱۵۰۰** | ۴:۵ | زیر ۳۰۰KB |
| `necklace-1.jpg` | سرویس گردنبند و انگشتر الماس | **۱۲۰۰ × ۱۲۰۰** | ۱:۱ | زیر ۲۰۰KB |
| `bracelet-1.jpg` | دستبند کارتیه طلا | **۱۲۰۰ × ۱۲۰۰** | ۱:۱ | زیر ۲۰۰KB |
| `ring-1.jpg` | انگشتر تک‌نگین یاقوت | **۱۲۰۰ × ۱۲۰۰** | ۱:۱ | زیر ۲۰۰KB |
| `pendant-1.jpg` | آویز طلا با سنگ فیروزه | **۱۲۰۰ × ۱۲۰۰** | ۱:۱ | زیر ۲۰۰KB |

### نکات عکاسی و آماده‌سازی

- **hero-bg.jpg:** عکس تیره و پرکنتراست (مثلاً رینگ‌لایت روی پارچه مخملی مشکی یا
  سنگ مرمر تیره). متن سفید/طلایی روی آن قرار می‌گیرد، پس گوشه سمت راست تصویر باید
  ساده و کم‌جزئیات باشد. تصویر با `cover` برش می‌خورد؛ سوژه را وسط کادر نگه دارید.
- **hero-side.jpg:** پرتره عمودی از یک قطعه یا مدل، با پس‌زمینه تیره و نور نرم؛
  سوژه در مرکز کادر بماند چون تصویر با `object-cover` برش می‌خورد. این قاب در
  موبایل پنهان است تا هیرو جمع‌وجور بماند (برای نمایش در موبایل، کلاس
  `hidden sm:block` را در `components/Hero.jsx` بردارید).
- **عکس محصولات:** مربع، پس‌زمینه یکدست (مشکی، کرم یا مرمر)، نور نرم و پخش‌شده،
  بدون سایه سخت. محصول باید حدود ۸۰٪ کادر را پر کند.
- فرمت `jpg` (کیفیت ۸۰) یا `webp`؛ در صورت استفاده از `webp` نام فایل در
  `data/products.js` را هم تغییر دهید.
- نام فایل‌ها دقیقاً مطابق جدول باشد (کوچک/بزرگ بودن حروف مهم است).

نیاز به فونت نیست، ولی اگر می‌خواهید تایپوگرافی دقیقاً **Vazirmatn** باشد، فایل
`Vazirmatn.woff2` را در `public/fonts/` بگذارید و در `app/globals.css` اضافه کنید:

```css
@font-face {
  font-family: 'Vazirmatn';
  src: url('/fonts/Vazirmatn.woff2') format('woff2');
  font-weight: 100 900;
  font-display: swap;
}
```

(در حالت انتشار در زیرمسیر، آدرس را با پیشوند مسیر مخزن بنویسید.)

## ۴) انتشار روی GitHub Pages

### روش خودکار (پیشنهادی)

فایل `.github/workflows/deploy.yml` آماده است:

1. کد را به شاخه `main` پوش کنید.
2. در GitHub: **Settings → Pages → Build and deployment → Source** را روی
   **GitHub Actions** بگذارید.
3. پس از هر push، سایت به‌صورت خودکار ساخته و منتشر می‌شود.

### نکته مهم: basePath

| آدرس سایت | مقدار `NEXT_PUBLIC_BASE_PATH` |
| --- | --- |
| `https://<user>.github.io/<repo>/` | `/<repo>` (workflow خودکار تنظیم می‌کند) |
| `https://<user>.github.io/` | خالی (خط `env` را در workflow حذف کنید) |
| دامنه اختصاصی مثل `zarin.ir` | خالی |

`next.config.js` این مقدار را می‌خواند و در `lib/path.js` به مسیر عکس‌ها اضافه
می‌شود؛ بنابراین عکس‌ها در زیرمسیر هم درست بارگذاری می‌شوند.

### روش دستی

```bash
npm run build
```

سپس محتویات پوشه `out/` را در شاخه `gh-pages` (یا در تنظیمات Pages) قرار دهید.
فایل `.nojekyll` از قبل داخل `out/` ساخته می‌شود؛ بدون آن GitHub Pages فولدر
`_next` را نادیده می‌گیرد و استایل‌ها بارگذاری نمی‌شوند.

## ۵) یادداشت‌های فنی

- `output: 'export'` و `images: { unoptimized: true }` طبق درخواست در
  `next.config.js` فعال است.
- در Next.js 14 اجرای `next dev` همراه با `output: 'export'` برای مسیرهای
  داینامیک خطای گمراه‌کننده «missing generateStaticParams» می‌دهد (باگ شناخته‌شده
  Next، در حالی که بیلد موفق است). به همین دلیل `output: 'export'` فقط برای بیلد
  پروداکشن اعمال می‌شود؛ `npm run build` همان خروجی استاتیک کامل را می‌سازد و
  `npm run dev` بدون خطا کار می‌کند.
- تصاویر محصول با تگ `<img>` معمولی رندر می‌شوند تا در حالت `basePath` مسیرها
  دوبار پیشوند نگیرند (در حالت export، بهینه‌سازی تصویر غیرفعال است و تفاوتی در
  خروجی ندارد).
- برای هر محصول یک صفحه استاتیک در `app/products/[slug]/page.jsx` ساخته می‌شود؛
  `generateStaticParams` مسیرها را از `data/products.js` می‌سازد و خروجی در
  `out/products/<slug>/index.html` قرار می‌گیرد (مثلاً
  `/products/ruby-solitaire-ring/`).
- دکمه «مشاهده جزئیات» هر کارت به همین صفحه لینک است و صفحات دیگر از طریق
  `next/link` به بخش‌های صفحه اصلی (`/#collection` و…) برمی‌گردند.
- سبد خرید با Context API و ذخیره در `localStorage` (کلید `zarin-cart-v1`) پیاده
  شده است؛ «ثبت سفارش» فقط شبیه‌سازی است: سبد خالی می‌شود و Toast تأیید نمایش
  داده می‌شود.
- نرخ‌های نوار بالای سایت در `data/goldPrices.js` تعریف شده‌اند و با تغییر همان
  اعداد به‌روز می‌شوند.
- رنگ‌ها و فونت‌ها در `tailwind.config.js` قابل تغییرند: `ink` (مشکی)، `gold`
  (طلایی)، `champagne` (کرم روشن).
